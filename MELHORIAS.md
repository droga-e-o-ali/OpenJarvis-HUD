# OpenJarvis HUD — melhorias planejadas

## 1. Comando de voz

Adicionar um botão de microfone no painel para falar a mensagem em vez de digitá-la. A primeira versão será de pressionar para falar, para preservar a privacidade e evitar ativações acidentais.

## 2. Voz para o Jarvis

Adicionar leitura automática das respostas em português, com controle para ligar/desligar e ajustar o volume. Em uma fase posterior, isso poderá usar uma voz local para continuar funcionando sem enviar áudio para a internet.

## 3. Interface melhor

Evoluir o HUD minimalista com animações discretas, escolha de cores, indicador de fala, histórico de conversas e atalhos de comandos — mantendo poucos elementos na tela.

## Como abrir

Dê duplo clique em `Abrir Jarvis HUD.cmd`. O painel inicia o servidor local do OpenJarvis e abre no navegador.
