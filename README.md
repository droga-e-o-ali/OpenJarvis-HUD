# OpenJarvis HUD

Interface local, minimalista e futurista para conversar com o OpenJarvis no navegador.

## Abrir

No Windows, dê duplo clique em `Abrir Jarvis HUD.cmd`.

O iniciador abre o painel em `http://127.0.0.1:8787` e executa a API do OpenJarvis somente no computador local.

## Requisitos

- OpenJarvis instalado em `%LOCALAPPDATA%\OpenJarvis\src`
- `uv` instalado pelo Winget
- Python 3.13 instalado
- Ollama em execução com o modelo configurado
